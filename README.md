## How I work with AI

I've written plenty of code by hand. These days I'd rather design systems than burn my evenings on implementation details, so I let AI do the typing and keep the thinking.

I'm not going to pretend I read everything. [tmop](https://github.com/tekikaito/tmop) is mostly unread (Rust is ugly), and so is most of [kshows](https://github.com/tekikaito/kshows): I needed a tool for my own cluster, it worked, problem solved. If it only serves me, "it works" is enough. Once other people, money or data are involved, I understand the architecture and every part that can hurt.

My take: if you still hand-write everything in 2026, you're mostly donating time. Typing code is cheap now. Deciding what to build, judging whether it's right and verifying it is the actual job.

There's no recipe. I build my own CLIs and TUIs around agents, run them in parallel, let them work on their own and step in where decisions matter. Tools get wired in wherever they pay off, and I keep tuning the whole setup.

In the end it comes down to common sense. Use your head while using AI and you can build genuinely cool things. A painting isn't judged by how gracefully the brush was swung, but by whether the result is beautiful.
