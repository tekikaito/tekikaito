## AI

I wrote a lot of code by hand before. Now I'd rather design the system and let AI do the implementation, as long as I still understand how it works.

I don't read everything. tmop is mostly unread (Rust is ugly), and so is most of kshows: I needed a tool for my own cluster and it works. Anything that involves other people, money or data, I read properly.

I build my own CLIs and TUIs to manage agents and run them in parallel. I don't follow a fixed workflow and keep tweaking it.

AI is a great tool if you bring some common sense: solid software engineering and CS fundamentals, an eye for long-term maintenance, and an honest idea of what AI can do and what it can't, yet.
